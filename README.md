# 🍪 Cookie Clicker AI Bot (YOLOv8)

Автоматизированный кликер для браузерной игры **Cookie Clicker** (Яндекс Игры), работающий на базе нейросети **YOLOv8**. 

Бот использует компьютерное зрение для распознавания игровых объектов и выполняет действия с нечеловеческой скоростью, не нагружая при этом браузер.

## ✨ Основные возможности
* **🏆 Умные клики по печеньке:** Бот кликает с заданной скоростью (по умолчанию 80 кликов/сек), которую невозможно достичь вручную, но при этом браузер не зависает.
* **🛑 Блокировка рекламы:** Мгновенно распознает всплывающие баннеры и закрывает их одним точным кликом по крестику.
* **🛒 Авто-покупка улучшений:** Раз в 20 секунд бот прокликивает магазин по заданным координатам, скупая доступные здания (Курсор, Бабушка, Ферма и т.д.).
* **⏸ Пауза на пробел:** Возможность мгновенно остановить и возобновить работу бота нажатием клавиши `Space`.
* **🛡 Безопасность:** Аварийная остановка при уводе мыши в левый верхний угол экрана.
